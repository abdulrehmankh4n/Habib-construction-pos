* **QR Code Scanning**

  * The application should be able to scan the QR/barcode of products to quickly identify and add items to a transaction.

* **Receipt & Customer Notifications**

  * When a receipt is created, the system should be able to send it to the customer via **WhatsApp and SMS**.

* **Customer Records & Credit Transactions**

  * The system should maintain a complete record of customers.
  * It should support customers who do not pay the full amount at the time of purchase.
  * The system should record outstanding amounts, payment history, and all previous transactions for each customer.
  * It should allow tracking of pending payments and transaction history.

* **Customer Information & Legal Documentation**

  * The system should be able to store important customer information, including:

    * CNIC number
    * Phone number
    * Full address
    * Transaction and payment history
  * It should have the ability to generate and print a **stamp-paper/legal agreement** containing the customer's information and payment terms.
  * The agreement should state that the customer agrees to repay the outstanding amount within a specified period, and that legal action may be taken if the amount is not paid within the agreed time.
  * The generated document should be printable on Pakistani legal/stamp paper.

* **Profit & Stock Analysis**

  * The application should provide profit analysis based on purchases and sales.
  * It should show:

    * Current stock quantity
    * Current stock value/worth
    * Purchase and selling values
    * Total profit
    * Outstanding customer payments
  * Reports should be available whenever required.

* **Zakat Calculation**

  * The system should have a dedicated **Zakat calculation** section.
  * Whenever required, the user should be able to generate a Zakat report based on the current stock.
  * The report should include:

    * Quantity of items
    * Current/worth value of items
    * Total value of eligible stock
    * Estimated Zakat amount payable
  * The Zakat report should be generated based on the stock and values available at that particular time.

* **Product Images**

  * The system should allow users to upload images for products.
  * When a product is searched, its image should be displayed next to the product name and details.

* **Multiple Systems / Real-Time Database**

  * Multiple computers/systems should be able to connect to the same central database.
  * The application can be installed and used on multiple machines simultaneously.
  * Stock, sales, purchases, customer records, and other data should be synchronized in **real time** across all connected systems.
  * For example, if an item is sold from one computer, the updated stock quantity should immediately be reflected on all other connected computers.
  * All systems should work with a single centralized database to maintain consistent and up-to-date records.
